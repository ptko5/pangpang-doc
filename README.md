# pangpang-doc

> 企业级研发文档库 —— 涵盖开发规范、环境搭建、部署运维、技术笔记、项目模板与知识管理。

## 项目简介

pangpang-doc 是公司研发团队的统一文档库，旨在沉淀研发全生命周期的规范、指南与经验，统一团队协作标准，提升研发效率与代码质量。

## 目录结构

```
pangpang-doc/
├── README.md                          # 项目总览与使用指南（本文件）
├── docs/                              # 文档主目录
│   ├── 00-开发规范/                    # 团队协作标准
│   ├── 01-环境搭建/                    # 开发/测试环境配置
│   ├── 02-部署运维/                    # 生产环境部署
│   ├── 03-技术笔记/                    # 技术沉淀与方案记录
│   ├── 04-项目模板/                    # 可复用的文档模板
│   └── 05-知识管理/                    # 学习方法与工具
├── assets/                            # 图片、截图等资源文件
│   └── images/
└── scripts/                           # 自动化脚本（如生成目录、检查链接）
```
