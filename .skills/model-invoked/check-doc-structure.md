## 检查规则

### R1: 文档头部信息块（强制）

**要求**：文档前 10 行内必须包含完整的「文档说明」表格。

**结构校验**：

1. 第 1 行：`# <标题>`（一级标题）
2. 第 2 行：空行
3. 第 3 行：`## <N>. 文档说明`（二级标题，N 为章节编号）
4. 第 4 行：空行
5. 第 5 行：`| 属性 | 说明 |`
6. 第 6 行：`|------|------|`
7. 第 7-10 行：必须包含 4 个属性行，属性名必须是以下之一且全部出现：

   - `文档版本`

   - `生效日期`

   - `适用范围`

   - `作者`

**格式校验**：

- 文档版本：正则 `V\d+\.\d+`（如 V1.0、V2.1）

- 生效日期：正则 `\d{4}-\d{2}-\d{2}`（如 2026-08-15）

### R2: 一级标题唯一（强制）

- 全文有且仅有 **一个** `# <内容>` 形式的一级标题

- 该一级标题必须位于文档第 1 行

### R3: 标题层级严格递增（强制）

- 遍历所有标题行（`#` 到 `######`）

- 当前标题的层级与上一个标题的层级差必须 ≤ 1

- 即：H1 → H2 ✅，H2 → H3 ✅，H1 → H3 ❌（跳级）

### R4: 章节编号格式（强制）

二级标题（`##`）推荐使用中文数字章节号：

```
✅ 正确：## 1. 文档说明 / ## 2. 核心立场 / ## 3. xxx
❌ 不推荐但不报错：## 文档说明（无章节号）
```

### R5: 文档结尾标记（强制）

文档末尾（去除空行后）必须包含以下 3 行结构：

```
---

**文档结束**

*本文档由 pangpang-doc 维护，解释权归架构组所有。*
```

判定方法：检查最后 10 行是否包含 `**文档结束**` 和 `*本文档由 pangpang-doc 维护` 两个字符串。

## 自动修复逻辑

### R1 自动修复

如果缺失完整的文档说明表格：

1. 从第 1 行提取标题
2. 在标题后插入以下模板：

```markdown

## 1. 文档说明

| 属性 | 说明 |
|------|------|
| 文档版本 | V1.0 |
| 生效日期 | <当前日期 YYYY-MM-DD> |
| 适用范围 | 公司所有研发团队 |
| 作者 | 架构组 |

---
```

1. 标记：`autofixed: true`，说明为「已自动插入文档说明表格模板，请核对」

### R2 自动修复

如果存在多个一级标题：

1. 将第 2 个及之后的 `# xxx` 降级为 `## xxx`
2. 标记：`autofixed: true`，说明为「已将多余一级标题降级为二级，请核对层级是否正确」

### R3 自动修复

检测到跳级（如 H1→H3）：

1. 找到缺失层级（H2），将 H3 直接升/降级补齐（H3→H2）
2. 标记：`autofixed: true`，说明为「已修复标题跳级：H#{from}→H#{to}，请核对语义层级」

### R5 自动修复

缺失结尾标记：

1. 在文档末尾追加标准结尾
2. 标记：`autofixed: true`
