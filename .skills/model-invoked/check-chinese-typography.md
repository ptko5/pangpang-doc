## 检查规则

### R1: 中英文之间必须加空格（强制）

中文字符（`\u4e00-\u9fff`）与英文字母（`a-zA-Z`）直接相邻时，中间必须有空格。

**正则检测（违规匹配）**：

```
[\u4e00-\u9fff][a-zA-Z]          // 中文 + 英文
[a-zA-Z][\u4e00-\u9fff]          // 英文 + 中文
```

**示例对照**：

| ✅ 正确        | ❌ 错误      |
| ----------- | --------- |
| 使用 React 框架 | 使用React框架 |
| 部署到 K8s 集群  | 部署到K8s集群  |
| JDK 25 新特性  | JDK25新特性  |

**豁免（不加空格）**：

- 反引号包裹内：`React框架`（整体是反引号术语，内部不加空格）

- 链接文本 `[xxx](url)` 中的 URL 部分

- 英文缩略词+中文翻译的括号模式：`微服务（Microservices）`

### R2: 中文与数字之间必须加空格（强制）

中文字符与阿拉伯数字（`0-9`）直接相邻时，中间必须有空格。

```
✅ 版本 2.0 / 共 500 行 / 2026 年
❌ 版本2.0 / 共500行 / 2026年（年份推荐加空格，不强制报错）
```

**豁免**：日期格式 `2026-08-15`、百分比 `50%`、带单位的数字紧邻符号（`V2.0` 整体）

### R3: 数字与单位之间必须加空格（强制）

```
✅ 500 行 / 32 GB / 2 小时 / 第 3 章
❌ 500行 / 32GB / 2小时 / 第3章
```

**豁免**：温度 `37°C`、角度 `90°`、百分比 `80%`、货币 `¥100` 等符号紧贴型单位。

### R4: 中文标点必须使用全角（强制）

中文正文中的标点符号（逗号、句号、问号、感叹号、冒号、分号、引号、括号、顿号）必须使用全角字符。

| 全角（正确）  | 半角（错误） |
| ------- | ------ |
| ，       | ,      |
| 。       | .      |
| ？       | ?      |
| ！       | !      |
| ：       | :      |
| ；       | ;      |
| 「」 / “” | ""     |
| （）      | ()     |
| 、       | 无对应    |

**豁免**：

- 代码块 ` ``` ` 内的内容

- 反引号 `` ` `` 内的内容

- 链接 URL 部分

- 英文句子中的标点（句中全是英文的，使用半角标点）

- 数学表达式和比例：`1:2:3`

### R5: 中文标点后面不加空格（强制）

全角标点 `，。；：！？）》」、` 后面直接跟字符，不加空格。

```
✅ 你好，世界。这是测试。
❌ 你好， 世界。 这是测试。
```

### R6: 半角标点使用场景（强制）

半角标点 **只能** 出现在以下场景：

1. 代码块 / 反引号内
2. 全英文段落
3. URL / 路径 / 域名（`https://`、`docs/00-开发规范/`）
4. 数学符号、版本号（`1.0.0`、`Spring Boot 4.x`）
5. 括号内的英文翻译（`（Microservices）` 用全角括号包半角英文）

## 自动修复逻辑

### R1 / R2 自动修复（中英文/数字空格）

对匹配违规正则的位置，自动插入空格：

```
// 算法伪代码：
text = text.replace(/([\u4e00-\u9fff])([a-zA-Z0-9])/g, "$1 $2")
           .replace(/([a-zA-Z0-9])([\u4e00-\u9fff])/g, "$1 $2")
```

**冲突处理**：

- 如果反引号包裹区域和中英文混杂重叠，跳过不处理

- 检查插入后是否会与已有空格重复（避免双重空格）

### R3 自动修复（数字与单位空格）

对常见中文单位匹配：

```
([0-9]+(?:\.[0-9]+)?)(行|个|项|章|节|条|份|分钟|小时|天|周|月|年|GB|MB|KB|TB|字节|次|人)
→ 替换为 $1 $2
```

### R4 自动修复（全角标点替换）

将中文正文中的半角标点替换为全角（仅在中文上下文，即前后 5 个字符内出现过中文的地方）：

```
, → ，    . → 。    ? → ？    ! → ！    : → ：    ; → ；
( → （    ) → ）    " → “”（智能识别左右）
```

**智能引号**：

- 半角 `"` 出现在奇数位置（开启）→ `“`

- 半角 `"` 出现在偶数位置（闭合）→ `”`

**排除代码块和反引号区域**：先提取保护区域 → 处理非保护区域 → 还原保护区域。

### R5 自动修复（标点后多余空格）

匹配 `[，。；：！？）》」] +`（全角标点后有空格），删除空格。

### R6 不自动修复

需人工判断半角标点是否在允许场景中。

***

## 自动修复前后冲突检测

执行修复前：

1. 先把所有代码块 ` ```...``` `、行内反引号 `` `xxx` ``、链接 URL `(url)` 提取为占位符（`{{CODE_BLOCK_N}}`）
2. 对正文文本执行 R1\~R5 修复
3. 还原占位符
4. 执行一次去重空格（多个空格变一个）
