### 2.2 目录职责说明

#### 【强制】分层职责

| 层级 | 职责 | 说明 |
|------|------|------|
| **api** | API接口定义 | 定义对外暴露的API接口和请求/响应对象 |
| **common** | 通用组件 | 全局配置、工具类、异常处理 |
| **service** | 业务逻辑 | 核心业务逻辑处理 |
| **infrastructure** | 基础设施 | 数据库访问、实体定义、外部依赖 |
| **adapter** | 适配器 | REST控制层、外部服务调用、消息处理 |
| **application** | 应用服务 | 应用层服务、命令处理 |
| **bootstrap** | 启动引导 | Spring Boot启动类、配置文件 |

### 3.2 目录职责说明

| **routes** | 路由配置 | 前端路由定义 |
| **styles** | 全局样式 | Less变量、混合、全局样式 |

## 4. 命名规范

### 4.1 文件命名规范

#### 【强制】文件命名

| 文件类型 | 命名规则 | 示例 |
|---------|---------|------|
| **Java类** | 大驼峰 | `UserController.java` |
| **TypeScript组件** | 大驼峰 | `UserList.tsx` |
| **样式文件** | 小驼峰 + `.module.less` | `UserList.module.less` |
| **工具函数** | 小驼峰 | `request.ts` |
| **状态管理** | 小驼峰 + `.store.ts` | `auth.store.ts` |
| **API文件** | 小驼峰 + `.api.ts` | `user.api.ts` |
| **类型定义** | 小驼峰 + `.ts` | `user.ts` |

### 4.2 目录命名规范

#### 【强制】目录命名

- 使用 **小写英文**
- 使用 **下划线** 分隔单词
- 使用 **复数形式** 表示集合

#### ✅ 正确示例

```
components/
pages/
hooks/
stores/
api/
utils/
types/
routes/
styles/
```

## 5. 依赖管理规范

### 5.1 Maven依赖管理

#### 【强制】依赖版本管理

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example</groupId>
    <artifactId>user-service</artifactId>
    <version>1.0.0</version>
    <packaging>pom</packaging>

    <modules>
        <module>api</module>
        <module>common</module>
        <module>service</module>
        <module>infrastructure</module>
        <module>adapter</module>
        <module>application</module>
        <module>bootstrap</module>
    </modules>

    <properties>
        <java.version>25</java.version>
        <spring-boot.version>4.0.0</spring-boot.version>
        <mybatis.version>3.0.0</mybatis.version>
        <spring-cloud.version>2024.0.0</spring-cloud.version>
    </properties>

    <dependencyManagement>
        <dependencies>
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-starter-parent</artifactId>
                <version>${spring-boot.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>

            <dependency>
                <groupId>org.mybatis.spring.boot</groupId>
                <artifactId>mybatis-spring-boot-starter</artifactId>
                <version>${mybatis.version}</version>
            </dependency>

            <dependency>
                <groupId>org.springframework.cloud</groupId>
                <artifactId>spring-cloud-dependencies</artifactId>
                <version>${spring-cloud.version}</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
        </dependencies>
    </dependencyManagement>
</project>
```

## 6. 配置文件规范

### 6.1 后端配置

#### 【强制】配置文件组织

```
backend/bootstrap/src/main/resources/
├── application.yml                        # 主配置文件
├── application-dev.yml                    # 开发环境
├── application-test.yml                   # 测试环境
├── application-staging.yml                # 预发环境
├── application-prod.yml                   # 生产环境
└── logback.xml                            # 日志配置
```

#### ✅ 正确示例

```yaml
# application.yml
server:
  port: 8080

spring:
  application:
    name: user-service
  profiles:
    active: ${SPRING_PROFILES_ACTIVE:dev}

logging:
  config: classpath:logback.xml
```

### 6.2 前端配置

#### 【强制】环境变量配置

```
frontend/
├── .env.development                       # 开发环境
├── .env.test                              # 测试环境
├── .env.staging                           # 预发环境
└── .env.production                        # 生产环境
```

#### ✅ 正确示例

```
# .env.development
VITE_API_BASE_URL=http://localhost:8080
```
