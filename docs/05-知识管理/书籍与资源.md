## 2. 后端书单（Java 方向）

| 阶段 | 书籍 | 说明 |
|------|------|------|
| 入门 | 《Java 核心技术》（卷 I） | Java 语言基础权威读物 |
| 进阶 | 《Effective Java》 | 编写高质量 Java 代码的 90 条建议 |
| 并发 | 《Java 并发编程的艺术》 | 锁、AQS、线程池底层原理 |
| JVM | 《深入理解 Java 虚拟机》 | JVM 内存、GC、调优圣经（配合 [JVM-调优案例](../03-技术笔记/问题排查/JVM-调优案例.md)） |
| 框架 | 《Spring 实战》/《Spring Boot 实战》 | 框架最佳实践 |
| 数据库 | 《高性能 MySQL》 | 索引、事务、性能优化 |

> 【推荐】入门书挑 1 本精读即可，进阶与源码类结合项目实践阅读，效果远优于通读。
