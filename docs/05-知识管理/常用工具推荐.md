# 常用工具推荐

## 1. 文档说明

| 属性 | 说明 |
|------|------|
| 文档版本 | V1.0 |
| 生效日期 | 2026-08-15 |
| 适用范围 | 公司所有研发人员 |

> **用途**：按场景分类推荐研发效率工具，覆盖开发、调试、文档协作、笔记与终端增强，并提供选型理由与替代方案，帮助团队统一工具链、减少重复选型成本。

---

## 2. 开发与调试工具

| 类别 | 推荐工具 | 说明 | 替代方案 |
|------|---------|------|---------|
| IDE | IntelliJ IDEA | JDK 25 + Spring Boot 4 支持完善，插件生态强 | VS Code |
| 构建 | Gradle 8.x | 公司标准构建工具，配置见 [Maven-Gradle-配置](../01-环境搭建/开发环境/Maven-Gradle-配置.md) | Maven |
| 数据库客户端 | DataGrip / Navicat | 可视化 SQL、ER 图、导入导出 | DBeaver |
| HTTP 调试 | Postman / Apifox | 接口调试、Mock、自动化测试 | HTTPie |
| 终端 | Warp / iTerm2 | 命令补全、分屏、快捷搜索 | Windows Terminal |
| 接口文档 | Apifox / Swagger | 在线调试 + 文档同步 | Knife4j |

> 【推荐】团队统一使用 Apifox（调试 + 文档一体化），减少 Postman 与文档工具之间的同步成本。

## 4. 文档与协作工具

| 场景 | 工具 | 说明 |
|------|------|------|
| 团队文档 | 飞书文档 | 在线协同、知识库、评论 |

## 5. 笔记与个人知识管理

| 工具 | 特点 | 适用人群 |
|------|------|---------|
| Obsidian | 本地 Markdown、双链、图谱 | 深度笔记用户 |
| 飞书云文档 | 在线、多端同步、团队共享 | 需要协作同步 |
| Anki | 间隔复习卡片 | 背诵记忆类学习 |
| Notion | 数据库化笔记、模板丰富 | 结构化知识库 |

> 推荐组合：Obsidian（个人沉淀）+ 飞书文档（团队共享）+ Anki（复习），分别承担「存、传、记」三个职能。
