#### 【强制】目录职责说明

| 目录 | 职责 | 说明 |
|------|------|------|
| **components** | 通用组件 | 可复用的UI组件，不包含业务逻辑 |

| **stores** | 状态管理 | Zustand store定义 |
| **api** | API接口 | 后端接口调用封装 |
| **utils** | 工具函数 | 纯函数工具类 |
| **types** | 类型定义 | TypeScript类型声明 |
| **constants** | 常量定义 | 静态常量 |
| **routes** | 路由配置 | React Router配置 |
| **styles** | 全局样式 | Less/CSS Modules |

## 3. 文件命名规范

### 3.1 组件文件命名

#### 【强制】组件文件命名规则

| 组件类型 | 命名规则 | 示例 |
|---------|---------|------|
| **普通组件** | 大驼峰（PascalCase） | `Button.tsx`, `Modal.tsx` |
| **页面组件** | 大驼峰（PascalCase） | `UserList.tsx`, `OrderForm.tsx` |
| **布局组件** | 大驼峰（PascalCase） | `Header.tsx`, `Sidebar.tsx` |
| **组件目录** | 小驼峰（camelCase） | `form/`, `table/`, `upload/` |

#### ✅ 正确示例

```
components/
├── layout/
│   ├── Header.tsx
│   ├── Sidebar.tsx
│   └── Footer.tsx
├── form/
│   ├── SearchForm.tsx
│   └── AdvancedSearch.tsx
└── table/
    └── StandardTable.tsx

pages/
├── login/
│   └── Login.tsx
├── dashboard/
│   └── Dashboard.tsx
└── user/
    ├── list/
    │   └── UserList.tsx
    └── form/
        └── UserForm.tsx
```

#### ❌ 错误示例

```
components/
├── layout/
│   ├── header.tsx           # 错误：使用小驼峰
│   └── sidebar.tsx          # 错误：使用小驼峰
└── Form/
    └── search_form.tsx      # 错误：使用下划线

pages/
├── user/
│   └── List.tsx             # 错误：名称不明确
```

## 4. 组件命名规范

### 4.1 组件类名/函数名

#### 【强制】组件命名规则

- 组件名称使用 **大驼峰（PascalCase）**
- 组件名称必须 **见名知意**
- 组件文件名必须与组件名称 **一致**

#### ✅ 正确示例

```tsx
// UserList.tsx
export default function UserList() {
  return <div>User List</div>;
}

// SearchForm.tsx
export default function SearchForm() {
  return <form>Search Form</form>;
}

// StandardTable.tsx
export default function StandardTable() {
  return <table>Standard Table</table>;
}
```

#### ❌ 错误示例

```tsx
// UserList.tsx
export default function userList() { }          // 错误：使用小驼峰
export default function UL() { }                // 错误：使用缩写

// searchForm.tsx
export default function SearchForm() { }        // 错误：文件名与组件名不一致
```

### 4.2 Props命名

#### 【强制】Props命名规则

- Props名称使用 **小驼峰（camelCase）**
- Props名称必须 **见名知意**
- 布尔类型Props使用 `is` / `has` / `can` 前缀

#### ✅ 正确示例

```tsx
interface UserListProps {
  users: User[];
  isLoading: boolean;
  hasMore: boolean;
  canEdit: boolean;
  onEdit: (id: number) => void;
  onDelete: (id: number) => void;
}

export default function UserList({ users, isLoading, hasMore, canEdit, onEdit, onDelete }: UserListProps) {
  // ...
}
```

## 5. 变量命名规范

### 5.1 普通变量

#### 【强制】变量命名规则

- 变量名使用 **小驼峰（camelCase）**
- 变量名必须 **见名知意**
- 集合类型变量使用 **复数形式**

#### ✅ 正确示例

```typescript
const userName = '张三';
const userList = [user1, user2, user3];
const isLoading = false;
const hasPermission = true;
const formattedDate = formatDate(date);
```

#### ❌ 错误示例

```typescript
const UserName = '张三';        // 错误：使用大驼峰
const user_list = [];           // 错误：使用下划线
const u = userService.getUser(); // 错误：使用缩写
const arr = [];                 // 错误：无意义命名
```

### 5.2 常量命名

#### 【强制】常量命名规则

- 使用 `const` 声明常量
- 常量名使用 **全大写 + 下划线**
- 常量定义在 `constants/` 目录下

#### ✅ 正确示例

```typescript
// constants/http.ts
export const HTTP_STATUS_OK = 200;
export const HTTP_STATUS_UNAUTHORIZED = 401;
export const HTTP_STATUS_FORBIDDEN = 403;
export const HTTP_STATUS_NOT_FOUND = 404;
export const HTTP_STATUS_ERROR = 500;

// constants/menu.ts
export const MENU_DASHBOARD = '/dashboard';
export const MENU_USER_LIST = '/user/list';
export const MENU_ORDER_LIST = '/order/list';
```

### 5.3 枚举命名

#### 【强制】枚举命名规则

- 枚举名使用 **大驼峰（PascalCase）**
- 枚举值使用 **全大写 + 下划线**

#### ✅ 正确示例

```typescript
export enum UserStatus {
  ACTIVE = 'ACTIVE',
  INACTIVE = 'INACTIVE',
  LOCKED = 'LOCKED',
}

export enum OrderStatus {
  PENDING = 'PENDING',
  PAID = 'PAID',
  SHIPPED = 'SHIPPED',
  COMPLETED = 'COMPLETED',
  CANCELLED = 'CANCELLED',
}
```

## 6. 函数命名规范

### 6.1 普通函数

#### 【强制】函数命名规则

- 函数名使用 **小驼峰（camelCase）**
- 函数名使用 **动词开头**
- 函数名必须 **见名知意**

#### ✅ 正确示例

```typescript
function getUserById(id: number): User { }
function createUser(user: CreateUserRequest): number { }
function updateUser(id: number, user: UpdateUserRequest): void { }
function deleteUser(id: number): void { }
function formatDate(date: Date): string { }
function validateEmail(email: string): boolean { }
```

#### ❌ 错误示例

```typescript
function getUser(id: number) { }      // 错误：语义不明确
function save(user: User) { }         // 错误：语义不明确（新增还是更新？）
function del(id: number) { }          // 错误：使用缩写
function UpdateUser(id: number) { }   // 错误：首字母大写
```

### 6.2 Hook函数

#### 【强制】Hook命名规则

- Hook函数名以 `use` 开头
- 使用 **小驼峰（camelCase）**

#### ✅ 正确示例

```typescript
function useAuth() { }
function useRequest<T>(url: string) { }
function useStorage<T>(key: string) { }
function useForm<T>(initialValues: T) { }
```

## 7. CSS命名规范

### 7.1 CSS Modules

#### 【强制】CSS Modules命名规则

- 使用 **小驼峰（camelCase）** 或 **kebab-case**
- 类名使用 **BEM风格**

#### ✅ 正确示例

```less
// UserList.module.less
.container {
  padding: 16px;
}

.title {
  font-size: 18px;
  font-weight: bold;
}

.userItem {
  display: flex;
  align-items: center;
  padding: 8px 0;
  border-bottom: 1px solid #eee;
  
  &:hover {
    background-color: #f5f5f5;
  }
}

.userName {
  font-size: 14px;
  color: #333;
}
```

```tsx
import styles from './UserList.module.less';

export default function UserList() {
  return (
    <div className={styles.container}>
      <h1 className={styles.title}>User List</h1>
      <div className={styles.userItem}>
        <span className={styles.userName}>张三</span>
      </div>
    </div>
  );
}
```

#### ❌ 错误示例

```less
// 错误：使用全大写
.CONTAINER { }

// 错误：使用下划线
.user_item { }
```

### 7.2 全局样式

#### 【强制】全局样式命名

- 使用 **kebab-case**
- 添加项目前缀，避免冲突

```less
// global.less
.app-container {
  min-height: 100vh;
}

.app-header {
  height: 64px;
  background-color: #fff;
  border-bottom: 1px solid #eee;
}

.app-sidebar {
  width: 200px;
  min-height: calc(100vh - 64px);
}
```
