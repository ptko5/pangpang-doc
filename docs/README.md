## 规范级别说明

本规范使用三级规范级别：

| 级别 | 标识 | 说明 |
|------|------|------|
| **强制** | 【强制】 | 必须严格遵守，违反将导致代码无法通过审查 |
| **推荐** | 【推荐】 | 建议遵守，有助于提高代码质量和团队协作 |
| **禁止** | 【禁止】 | 严格禁止，违反将导致代码无法通过审查 |

## 使用指南

### 1. 新团队成员入门

1. 阅读 **模块1：研发组织与分支管理规范**，了解Git工作流
2. 根据技术栈阅读对应的编码规范（模块2或模块3）
3. 阅读 **模块5：API接口统一规范**，了解接口设计规范
4. 阅读 **模块10：项目目录分层规范**，了解项目结构

### 2. 代码审查

1. 检查是否符合编码规范（模块2或模块3）
2. 检查是否符合数据库设计规范（模块4）
3. 检查是否符合安全开发规范（模块8）
4. 检查测试覆盖率是否达标（模块7）

### 3. 项目部署

1. 参考 **模块9：部署与运维规范** 进行部署
2. 参考 **模块6：微服务架构规范** 进行服务治理
