## 规范级别说明

本规范使用三级规范级别：

| 级别 | 标识 | 说明 |
|------|------|------|
| **强制** | 【强制】 | 必须严格遵守，违反将导致代码无法通过审查 |
| **推荐** | 【推荐】 | 建议遵守，有助于提高代码质量和团队协作 |
| **禁止** | 【禁止】 | 严格禁止，违反将导致代码无法通过审查 |

## 使用指南

### 1. 新团队成员入门

1. 阅读 [Git-工作流规范](00-开发规范/Git-工作流规范.md)，了解 Git 工作流与分支策略
2. 根据技术栈阅读对应的编码规范（[后端](00-开发规范/后端开发规范/Java-编码规范.md) 或 [前端](00-开发规范/前端开发规范/前端工程化规范.md)）
3. 阅读 [RESTful-API-设计规范](00-开发规范/后端开发规范/RESTful-API-设计规范.md)，了解接口设计规范
4. 阅读 [命名规范](00-开发规范/命名规范.md)，了解项目结构与命名约定

### 2. 环境搭建

1. 参考 [01-环境搭建](01-环境搭建/README.md) 配置开发环境
2. 安装所需中间件（MySQL、Redis 等）

### 3. 代码审查

1. 检查是否符合编码规范（后端 / 前端开发规范）
2. 检查是否符合 [数据库开发规范](00-开发规范/后端开发规范/数据库开发规范.md)
3. 检查是否符合 [安全开发规范](00-开发规范/安全开发规范.md)
4. 检查测试覆盖率是否达标（[测试规范](00-开发规范/测试规范.md)）

### 4. 项目部署

1. 参考 [02-部署运维](02-部署运维/README.md) 进行部署
2. 参考 [微服务架构设计](03-技术笔记/架构设计/微服务架构设计.md) 进行服务治理

### 5. 文档撰写

1. 使用 [04-项目模板](04-项目模板/) 中的模板快速创建文档
2. 遵循 [文档书写规范](00-开发规范/文档书写规范.md)
