## 规范概述

本规范手册旨在统一公司全研发团队的开发标准，覆盖研发全生命周期，包括：

| 模块 | 内容 | 核心关注点 |
|------|------|-----------|
| **模块1** | 研发组织与分支管理规范 | Git工作流、分支策略、代码评审 |
| **模块2** | 后端Java编码规范 | JDK25特性、命名规范、异常处理、安全 |
| **模块3** | 前端React+TS+Antd编码规范 | TypeScript、Hooks、状态管理、性能 |
| **模块4** | 数据库设计规范 | 命名规范、索引设计、分库分表 |
| **模块5** | API接口统一规范 | RESTful设计、统一响应格式 |
| **模块6** | 微服务架构规范 | 服务治理、通信方式、分布式事务 |
| **模块7** | 测试规范 | 测试分层、测试覆盖率、CI/CD集成 |
| **模块8** | 安全开发规范 | 认证授权、输入验证、安全防护 |
| **模块9** | 部署与运维规范 | Docker、Kubernetes、监控告警 |
| **模块10** | 项目目录分层规范 | 前后端目录结构、命名规范 |

## 规范级别说明

本规范使用三级规范级别：

| 级别 | 标识 | 说明 |
|------|------|------|
| **强制** | 【强制】 | 必须严格遵守，违反将导致代码无法通过审查 |
| **推荐** | 【推荐】 | 建议遵守，有助于提高代码质量和团队协作 |
| **禁止** | 【禁止】 | 严格禁止，违反将导致代码无法通过审查 |

## 使用指南

### 1. 新团队成员入门

1. 阅读 **模块1：研发组织与分支管理规范**，了解Git工作流
2. 根据技术栈阅读对应的编码规范（模块2或模块3）
3. 阅读 **模块5：API接口统一规范**，了解接口设计规范
4. 阅读 **模块10：项目目录分层规范**，了解项目结构

### 2. 代码审查

1. 检查是否符合编码规范（模块2或模块3）
2. 检查是否符合数据库设计规范（模块4）
3. 检查是否符合安全开发规范（模块8）
4. 检查测试覆盖率是否达标（模块7）

### 3. 项目部署

1. 参考 **模块9：部署与运维规范** 进行部署
2. 参考 **模块6：微服务架构规范** 进行服务治理
