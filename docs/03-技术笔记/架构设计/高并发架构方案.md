## 2. 背景与目标

### 2.1 背景

- 业务存在秒杀、促销等瞬时高流量场景
- 需要支撑更高的吞吐与更低的响应，且保护下游不被打垮

### 2.2 目标

| 目标 | 指标 |
|------|------|
| 支撑峰值 QPS | 万级 |
| P99 响应时间 | < 500ms |
| 系统可用性 | 99.9%+ |
| 下游保护 | 限流/熔断/降级全覆盖 |

---

## 3. 分层架构

```text
接入层(CDN/Nginx) ──> 网关层(Gateway/限流) ──> 应用层(服务) ──> 数据层(Redis/MySQL/MQ)
```

| 层 | 职责 | 关键技术 |
|----|------|---------|
| 接入层 | 静态资源、SSL、WAF | CDN、Nginx |
| 网关层 | 路由、鉴权、限流 | Spring Cloud Gateway + Redis 限流 |
| 应用层 | 业务逻辑 | 微服务、无状态化 |
| 数据层 | 缓存/存储/异步 | Redis Cluster、MySQL、Kafka/RabbitMQ |

> 【推荐】应用无状态化（Session 外置），便于横向扩容。

## 4. 流量治理

### 4.1 限流（保护自身）

| 算法 | 说明 | 适用 |
|------|------|------|
| 固定窗口 | 简单但边界突刺 | 低频场景 |
| 滑动窗口 | 平滑，精度更高 | 通用 |
| 令牌桶 | 允许突发，平滑 | 接口限流（推荐） |
| 漏桶 | 恒定速率 | 保护下游 |

```java
// Spring Cloud Gateway + Redis 令牌桶限流示例
@Configuration
public class RateLimitConfig {
    @Bean
    public KeyResolver userKeyResolver() {
        return exchange -> Mono.just(
            exchange.getRequest().getRemoteAddress().getAddress().getHostAddress());
    }
}
```

### 4.2 熔断（快速失败）

- 依赖故障达到阈值（错误率 > 50%）时熔断，快速返回兜底
- 常用：Resilience4j / Sentinel

```yaml
resilience4j:
  circuitbreaker:
    instances:
      orderService:
        failureRateThreshold: 50
        slidingWindowSize: 100
```

### 4.3 降级（保证核心）

| 级别 | 策略 |
|------|------|
| 一级 | 核心交易保留，日志/推荐等降级 |
| 二级 | 非关键服务关闭或降级 |
| 三级 | 兜底文案/缓存数据响应 |

> 【强制】关键路径必须设计降级开关，高峰前按预案执行。

## 5. 异步化

### 5.1 适用场景

| 场景 | 同步改异步方式 |
|------|---------------|
| 秒杀扣库存 | 请求入队，异步削峰 |
| 下单通知 | MQ 异步发送 |
| 数据统计 | 异步落库/清洗 |
| 大任务 | 拆分 + 消息驱动 |

### 5.2 削峰填谷示例

```text
请求 ──> 网关限流 ──> MQ(削峰) ──> 消费(恒定速率) ──> DB
```

```java
// 秒杀库存扣减：先缓存预扣减，再异步持久化
boolean allowed = redisStock.decrement("stock:10001");
if (allowed) {
    kafkaTemplate.send("order-create", payload); // 异步落库
}
```

## 7. 容量规划

### 7.1 容量预估公式

```text
单实例 QPS 上限 ≈ 1000（经验值，需压测验证）
所需实例数 = 预估峰值 QPS ÷ 单实例 QPS × 冗余系数(1.5)
```

### 7.2 压测验证

```bash
# 使用压测工具（JMeter / wrk / Gatling）
wrk -t8 -c400 -d60s http://localhost:8080/api/orders
```

> 【强制】上线前必须完成压测，输出单实例 QPS 与容量规划报告。

## 8. 风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| 峰值流量击穿 | 高 | 限流 + 削峰 + 熔断 |
| 下游依赖故障 | 高 | 熔断 + 降级 + 重试退避 |
| 数据不一致 | 中 | 幂等 + 最终一致 |
| 容量不足 | 高 | 压测 + 弹性扩容（K8s HPA） |
| 缓存雪崩 | 高 | TTL 随机 + 多级缓存 |
